## 三、本地运行

```bash
python -m http.server 8899 --bind 127.0.0.1     # 站点根＝本仓库
# 游戏：http://127.0.0.1:8899/hexiang/
# 展示站：http://127.0.0.1:8899/
```

回归测试（需 Chrome；端口与浏览器路径可用环境变量覆盖）：

```bash
node hexiang/tests/game_v2_test.js      # TEST_PORT=8897 CHROME_PATH=...
node hexiang/tests/gen_assets.js        # 扫描素材 → 重生成素材谱 + 各城需求清单
node hexiang/tests/live_check.js        # 打线上 Pages 实测
```
